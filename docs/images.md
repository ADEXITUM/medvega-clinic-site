# Источники изображений

| Изображение | Где используется | Источник |
|---|---|---|
| Иллюстрация «Клиника» (`app/components/HeroIllustration.vue`) | Главная, первый экран | Векторная иллюстрация выполнена автором проекта в SVG |
| Иллюстрации помещений (inline SVG) | «О клинике», раздел «Фотографии клиники» | Выполнены автором в SVG; фотографии реальных помещений не используются, т. к. компания вымышленная |
| Аватары врачей с инициалами (`app/components/DoctorAvatar.vue`) | Карточки и страницы врачей | Генерируются из ФИО средствами CSS, по п. 4.3 ТЗ вместо портретов |
| Логотип и favicon (`app/components/AppLogo.vue`, `public/favicon.svg`) | Шапка, подвал, вкладка браузера | Выполнены автором в SVG |
| Иконки интерфейса | Весь сайт | Библиотека Lucide (`@lucide/vue`), лицензия ISC, https://lucide.dev |
| Шрифт Manrope | Весь сайт | Google Fonts через пакет `@fontsource/manrope`, лицензия SIL Open Font License 1.1 |
| `public/og-image.png` | Превью в соцсетях (Open Graph) | Скриншот главной страницы сайта, `scripts/screens.mjs` |
| Карта | «Контакты» | © участники OpenStreetMap, лицензия ODbL, встраивается через iframe |

Фотографии из фотобанков в проекте не используются, поэтому растровых изображений, требующих конвертации в WebP/AVIF, на страницах нет.
